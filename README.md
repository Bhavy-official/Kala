# KALĀ — The Living Art of India

An immersive, interactive digital atlas dedicated to celebrating India's rich cultural geography, regional art forms, and sacred architectures.

---

## 🌟 Overview

**KALĀ** takes you on a visual and educational journey across 28 states and 8 union territories of India, bridging 30,000 years of recorded art history—from ancient cave paintings and classical temple architecture to living craft traditions.

### ✨ Key Features
- **Cinematic Hero**: Dynamic typography with GSAP reveals and parallax visuals.
- **Narrative Chapters**: Three scroll-driven chapters exploring cultural diversity, regional identity, and artistic medium.
- **Interactive Map of India**: Custom vector cartography highlighting each state and union territory, featuring interactive hover effects and click-to-inspect capabilities.
- **State Cultural Inspector**: Deep dive into individual state traditions, capital, heritage sites, and notable art forms with smooth Framer Motion transitions.
- **Art Forms Gallery**: Curated interactive gallery spotlighting Madhubani, Warli, Pattachitra, Tanjore, Gond, and Kalamkari.
- **Museum Aesthetic**: Deep earthen palette, warm gold & terracotta accents, subtle grain texture, and refined typography (*Cormorant Garamond* & *Manrope*).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/Bhavy-official/Kala.git

# Navigate to project folder
cd Kala

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
